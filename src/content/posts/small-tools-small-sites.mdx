There is a particular pleasure in opening a website and having it simply appear. No spinner, no cookie banner, no layout shifting into place. The text is there, the type is readable, and nothing is asking for your attention.

I keep coming back to that feeling when I build things. Most of the software I admire is not clever in the way that demos are clever. It is small, predictable, and quiet.

## The cost of convenience

It is easy to add things to a website. A comment system, a newsletter popup, an analytics dashboard, a font loader, a framework for the framework. Each one is reasonable on its own. Together they turn a page into a small application that happens to contain paragraphs.

The cost is not only kilobytes. It is the number of decisions you have to make before you can publish a sentence. Every dependency is a surface area for maintenance, and every moving part is a place where the site can fail while you are asleep.

A static site is not a moral achievement. It is just a useful constraint.

> Make the thing as simple as it can be, but not simpler. Then make it a little simpler anyway.

## What a static file gets you

When the output of a build is a folder of HTML, CSS, and a handful of images, a few good things follow:

- Hosting is cheap or free.
- There is no database to patch.
- The site can be served from anywhere.
- A page that was fast last year is still fast this year.
- You can read the whole source in an afternoon.

The last one matters more than it sounds. A personal website should be something you can understand completely, even if you step away for a year. If coming back requires re-learning a stack, the stack is too big for the job.

## A smaller definition of enough

This site currently has three pages of writing, one font pairing, and no comments. It has a dark mode because I like reading in the dark, and an RSS feed because the open web still works. That is close to the whole feature list.

There are things I miss. I would like a better way to search old notes. I would like to know which posts people actually read.[^1] But those are additions I can make later, deliberately, when the absence becomes annoying enough to justify the weight.

For now, the constraint is the point. A small site is easier to keep alive. And a site that stays alive is more useful than one that was impressive for a season.

[^1]: This is where a privacy-friendly analytics tool earns its place. GoatCounter counts page views without cookies, which feels like the right trade for a personal blog.
